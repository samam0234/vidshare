## 2. Phase A — 백엔드 기반 (우선)

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 인증 | 회원가입, 로그인, 세션/JWT | P0 |
| 사용자 프로필 API | id·핸들·아바타 DB 연동 | P0 |
| 쇼츠 CRUD | 목록·상세·생성·삭제 | P0 |
| 파일 스토리지 | 영상·썸네일 업로드 | P0 |
| 댓글 API | 영속 댓글 | P1 |
| 좋아요 API | 사용자별 토글, 카운트 | P1 |

## 3. Phase B — 제품 기능

| 기능 | 설명 | 우선순위 |
|------|------|----------|

| 실시간 메시지 | WebSocket/SSE 채팅 | P2 |
