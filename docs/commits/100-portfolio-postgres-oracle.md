## 4. 발견한 기존 버그

| 버그 | 영향 | 처리 |
|------|------|------|
| 사이트 `.code` 에 `white-space` 지정이 없음 | 4개 페이지 **코드 블록 18개 전부** 줄바꿈이 사라져 한 덩어리로 보임 (20줄 구조도가 127px) | `white-space: pre` — 485px 로 펼쳐짐. 모바일은 기존 `overflow-x: auto` 로 가로 스크롤 |
| docx 변환기가 굵게 안의 인라인 코드를 해석하지 않음 | 설계 원칙 등 6문단에 백틱이 그대로 찍힘 | 굵게 조각을 다시 나눠 코드 글꼴로 |

새로 넣은 사이트 구조도의 윈도우 경로(`D:\…`)가 생성 스크립트에서 제어 문자(`\v`, `\b`)로 바뀌어 들어간 것도 렌더링 확인 중에 발견해 `&#92;` 로 고쳤고, 이번에 바뀐 파일 99개에 제어 문자가 없는지 검사했다.

## 5. 검증

- **슬라이드**: PowerPoint COM 으로 열어(24장) 바뀐 7장을 PNG 로 내보내 확인. 표지는 이전 덱과 렌더링이 같음.
  "운영 준비" 슬라이드는 숫자-설명 간격을 한 번 고쳤고, "코드를 올릴 때마다 실행"은 E2E 를 뺀 180 으로 정정.
- **문서**: docx 본문을 python-docx 로 뽑아 새 내용 포함·`**`/`~~` 0건 확인. 남은 백틱 0건.
- **사이트**: Playwright 로 1280px · 390px 렌더링 — 가로 넘침 0px, 코드 블록 18개 `white-space: pre` 확인, 구조도 스크린샷 확인.
