## 2. 개요

065에서 팔로우 API를 만들었지만 **팔로잉 피드를 볼 화면이 없었다.**
팔로우 버튼은 동작하는데 팔로우한 결과를 확인할 방법이 없어,
사용자 입장에서는 팔로우의 효용을 체감할 수 없는 반쪽 기능이었다.

065 문서의 "남은 한계 1번"으로 명시해 둔 항목이다.

## 4. 구현

### 재사용

새 카드 컴포넌트를 만들지 않고 프로필의 `VideoGrid` 와 `toProfileVideos()` 를 그대로 썼다.
쇼츠 썸네일 그리드라는 표현이 동일하므로 별도 UI를 만들 이유가 없다.

### 상태별 화면

| 조건 | 화면 |
|------|------|
| `!ready \|\| loading` | "불러오는 중..." |
| 비로그인 | 로그인 유도 + `/login?next=/following` |
| 에러 | 에러 메시지 |
| 결과 0건 | "팔로우한 크리에이터가 없거나 영상이 없습니다" + 검색 유도 |
| 결과 있음 | `VideoGrid` |

빈 상태에서 `/search` 로 보내, 팔로우할 사람을 찾는 다음 행동까지 이어지게 했다.

### 비로그인 처리

`/api/follows/feed` 는 인증이 필요하므로 API를 아예 호출하지 않고
로그인 안내를 보여준다. 401을 받아 처리하는 것보다 요청 한 번을 아낀다.

### Navbar

회원 메뉴에만 추가했다. 비회원에게는 의미가 없는 화면이다.

## 6. 남은 한계

1. **쇼츠만 나온다** — 팔로우한 사람의 롱폼·커뮤니티 글은 포함되지 않는다.
   `/api/follows/feed` 자체가 쇼츠 전용이다.
2. **페이지네이션 없음** — 서버가 `limit 50` 으로 자르고 "더 보기"가 없다.
3. **자동 갱신 없음** — 페이지에 머무는 동안 새 영상이 올라와도 반영되지 않는다.
